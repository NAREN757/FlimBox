🎬 FilmBox
A Netflix-inspired movie discovery platform built with Antigravity that helps users explore movies, watch trailers, and discover personalized movie recommendations using AI.
✨ Features
🎥 Browse trending and popular movies
🔍 Search movies instantly
▶️ Watch official movie trailers
🎯 AI-powered movie recommendations
⭐ View movie details, ratings, and genres
📱 Fully responsive Netflix-inspired UI
⚡ Fast and intuitive user experience
🛠️ Tech Stack
Antigravity
JavaScript / TypeScript
HTML5
CSS3
Movie API (TMDB or equivalent)
AI Recommendation System
